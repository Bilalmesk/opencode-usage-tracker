What is exact — and what isn’t the cap is not published
  • Request-counted, not token-counted. The free tier is a 24-hour request bucket keyed to your public network and shared by every app or device on it. Token totals are information, not the trigger.
  • The cap is private and dynamic. OpenCode keeps it in the server-side ZEN_LIMITS secret and exposes no remaining-quota API or header. The only published free-model number is LongCat 2.5 Free at 100 requests/day.
  • The only exact reset is a 429. While a refusal is pending, the countdown uses the server’s retryAfterMs. Otherwise it is a range: 24h after the first request this machine saw, and earlier if another device on the network opened the window first.
  • “Headroom” is not remaining quota. It is the last refused window’s observed request count minus this window’s count — a historical boundary, not the server’s cap.
